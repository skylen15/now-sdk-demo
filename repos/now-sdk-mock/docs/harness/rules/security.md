# Security Rules

- Personal Todo data is private to the owning user by default.
- Owner-only access must be enforced by platform/server controls, not only by UI filters.
- Normal users must not read, update, or delete another user's tasks, tags, task-tag mappings, saved filters, recurrence data, or reminders.
- Admin/developer support access must be explicit and must not weaken normal user isolation.
- Team/workgroup sharing, watchers, comments, and assignment workflows are out of scope for v1.
