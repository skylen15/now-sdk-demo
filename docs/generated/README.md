# Generated Documentation

This directory contains generated, reviewable documentation derived from source
code, metadata, schemas, or tooling.

## Rules

- Do not edit generated documents by hand.
- Each generated document must identify its source and regeneration command.
- Generation must be deterministic and must not require undocumented secrets.
- Generated documents are supporting references, not authoritative substitutes
  for source code, Fluent metadata, ServiceNow records, or harness state.
- Do not place Now SDK build output here; `dist/` and `.now/` remain tool-owned.

No generated documentation is currently committed.
