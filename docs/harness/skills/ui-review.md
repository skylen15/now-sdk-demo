# UI Review Skill

Use this skill to review React UI and user experience concerns for the Personal Todo app.

## Review Areas

- React 18 UI Page behavior
- TodoMVC-like task capture and list interactions
- TanStack Router and Query usage
- Loading, empty, error, and no-results states
- Dense, native-feeling ServiceNow UI

## Rules

- The first screen is the working todo interface, not a landing page.
- Keep the layout dense, scannable, and stable.
- Before recommending custom UI code, verify whether ServiceNow React components, UI Page patterns, TanStack Router/Query, or existing project components already provide the needed implementation pattern.
- Prefer ServiceNow React components where appropriate and supported.
- Do not add team navigation or marketing content.

## Output Checklist

- [ ] UI findings (what visual or experience issues were identified?)
- [ ] Interaction requirements (how should user actions be handled?)
- [ ] Visual/state requirements (how are loading, empty, and error states represented?)
- [ ] Smoke test scenarios (what manual or automated UI tests are recommended?)
