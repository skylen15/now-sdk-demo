# Story Workflow

## Intake

- Run `npm run harness:init`.
- Read `AGENTS.md`, harness state, session handoff, backlog, and the active story.
- Work on exactly one active story.

## Review And Implementation

- Review acceptance criteria, project rules, and relevant skills before editing.
- Preserve unrelated user changes.
- Record durable decisions in `decisions.md`.

## Validation And Handoff

- Follow `verification.md`.
- Update state and session handoff with evidence, remaining work, and blockers.
