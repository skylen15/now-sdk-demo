# Harness Skill Packages

Harness skills are portable base-spec Agent Skill packages. Each package has a `SKILL.md` with `name` and `description` frontmatter plus task-specific instructions.

Use these skills as reusable expertise during intake, implementation, review, validation, and documentation. Use subagents only when work needs isolated context, parallel execution, permission scoping, or noisy long-running output; any subagent should follow the same relevant skill package.

- `platform-review/SKILL.md`
- `security-review/SKILL.md`
- `ui-review/SKILL.md`
- `test-review/SKILL.md`
- `docs-review/SKILL.md`
- `context7/SKILL.md`
- `sn-docs/SKILL.md`
